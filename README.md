# LASER AI

A polished AI workspace UI inspired by the supplied reference.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` for a production build check.

## Scope

LASER AI includes local conversation history, working navigation/context panels, suggested prompts, a message composer, and copyable code blocks. No AI provider or fake model response is included; connect a backend adapter when credentials and the provider are available.
